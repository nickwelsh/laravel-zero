# Laravel Zero

Laravel-owned model contracts, queries and automatic CRUD for Rocicorp Zero.

Development takes place in the [source monorepo](https://github.com/nickwelsh/laravel-zero-monorepo).
`nickwelsh/laravel-zero` is the generated PHP distribution mirror. Send issues and
pull requests to the monorepo; changes made directly to the mirror are not supported.

See the [monorepo documentation](https://github.com/nickwelsh/laravel-zero-monorepo#readme) for installation, authorization, configuration and React usage.

Requires PHP 8.3+ and Laravel 12 or 13.
